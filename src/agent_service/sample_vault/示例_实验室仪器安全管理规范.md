# 实验室大型仪器设备安全与使用管理规范

## 1. 准入与考核制度
- 任何课题组成员在独立操作大型仪器（包括 [[示例_SEM扫描电子显微镜操作SOP]] 所列显微镜、超算集群）前，必须通过理论考核与 3 次实操演练。
- 未经培训私自开机者，暂停实验室操作权限两周。

## 2. 仪器预约与使用记录
- 实行实名制预约系统，单次预约最长不超过 4 小时；
- 实验结束后必须在纸质登记本和云端系统同步填写：使用者姓名、运行时间、加速电压、样品类型与仪器状态。

## 3. 突发事故应急预案
- 如遇仪器异响、真空度骤降或出现高压电弧报警，立即按下红色 **EMERGENCY STOP (紧急停机)** 按钮；
- 第一时间切断主电源，并向安全员汇报，严禁私自拆卸真空舱与透镜组。
