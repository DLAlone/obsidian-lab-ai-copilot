# 深度学习基础概念与大模型前沿

## 1. 核心架构演变
- 传统序列模型依赖 RNN/LSTM 处理时序数据，但面临长程依赖梯度消失和难以并行计算的瓶颈。
- 详细架构见 [[示例_Attention_Is_All_You_Need_文献研读]]，Transformer 的出现彻底改写了自然语言处理与多模态模型的发展格局。

## 2. 检索增强生成 (RAG, Retrieval-Augmented Generation)
- **概念**：结合私有知识库检索与大模型推理能力的混合范式，旨在消除模型幻觉，提供学术事实溯源能力。
- **检索策略对比**：
  1. 向量相似度检索 (Vector Search)；
  2. 双链知识图谱遍历 (Knowledge Graph RAG)；
  3. 倒排关键词词频检索 (BM25)。
